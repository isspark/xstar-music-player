# XSTAR 底部导航 · 10 套 HTML 原型

直接用浏览器打开 `index.html`。样式、图标和封面均在本地生成，无网络依赖。桌面适合横向比较，手机浏览器适合查看接近实际 APP 的尺寸；各方案「单独体验」可切换为单机界面。

## 设计依据

- 配色来自 `ScenePlayer.kt` 中的 Classic、Orbital、Theatre、Liquid、Tape 听歌空间，沿用 `PageChrome.kt` 的主题继承思路。
- 圆角卡片、主题强调色、轻描边与即时保存对应现有外观设置语言。
- 入口替换参考 `AppearanceFloatingButton`：按槽位选择，已使用项不可重复，提供恢复默认。仅采用导航页面，不把分享、播放模式等动作伪装成页面。

## 可操作内容

- 「方案对比」展示所有底栏；「实际体验」的底栏默认关闭，需在外观设置开启。设置保存在当前浏览器。
- 5 个默认入口：在线搜歌、音乐库、播放页、主题外观、设置。
- 3 个默认入口：在线搜歌、播放页、音乐库。3/5 的入口配置分别记忆。
- 所有槽位包括中间槽位均可替换为页面，例如我的收藏。中间始终是视觉主位；音乐动效属于播放页入口，中间被换成其他页面后不再显示音乐频谱。
- 点击导航展示对应页面草图；播放页与导航保持独立，单击播放页入口只负责导航。
- 暂停、切歌、拖动进度、主题切换、收藏反馈、演示音乐搜索均可操作。设置、定时、均衡器等为页面示意。
- 初始为无声模拟音乐信号；导入本地音频后使用 Web Audio AnalyserNode 获取真实频谱和时域波形。文件不会上传。浏览器不支持的音频格式会返回演示模式。
- 暂停或关闭音乐动效后停止律动；尊重系统减少动态效果设置。离屏方案跳过绘制。

## 正式 APP 的音乐联动映射建议

将原型的低频能量、频谱分段、波形、进度、当前歌词分别接入现有 `SpectrumModels` / `SpectrumAudioProcessor`、播放器状态与歌词状态。无歌曲时使用音乐符号占位；暂停保持静态轮廓；切歌更新封面色、歌词字与进度。原型封面、曲目与歌词为设计演示，真实导入音频不解析封面和歌词。

底栏内容建议 64–76 dp，中央主键约 56–64 dp；触摸目标至少 44–48 dp，另加系统手势区。正式布局应由底栏占用内容高度，避免遮住播放控件和末行歌词；键盘展开时收起底栏。此原型通过内容底部留白和安全区演示固定栏。
