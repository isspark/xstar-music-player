# 本地音乐播放器需求文档

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | XSTAR |
| 文档版本 | 1.0 |
| 产品阶段 | MVP |
| Android 包名 | `life.xstar.music.player` |
| 目标平台 | Android 手机和平板 |
| 数据来源 | 用户设备上的本地音频文件 |
| 网络依赖 | MVP 不依赖网络 |

## 2. 产品概述

XSTAR 是一款面向 Android 用户的本地音乐播放器。应用读取设备系统媒体库中的音频文件，建立本地音乐索引，并提供歌曲浏览、搜索、播放队列、后台播放、播放列表和收藏等能力。

产品的核心价值是：在不登录、不上传音乐、不依赖在线服务的前提下，让用户稳定、快速地播放和管理设备中的音乐。

### 2.1 应用标识与首版决策

- 应用名称：XSTAR。
- Android `applicationId` 和 `namespace`：`life.xstar.music.player`。
- 首版目标：V0.1 可播放版本。
- 建议最低支持版本：Android 8.0（最终以设备覆盖率确认）。
- 首版不提供账号体系、云同步和网络音乐服务。
- 首版不修改、移动或删除设备中的原始音频文件。

## 3. 产品目标

### 3.1 MVP 目标

- 用户授权后能够发现设备中的本地音乐。
- 用户能够按歌曲、专辑和艺术家浏览音乐。
- 用户能够稳定完成播放、暂停、切歌、拖动进度和调整播放模式。
- 应用退到后台、锁屏或使用蓝牙耳机时仍能够控制播放。
- 用户能够使用收藏和自定义播放列表管理音乐。
- 应用重启后能够恢复合理的播放上下文。

### 3.2 非目标

MVP 不包含以下能力：

- 在线音乐搜索、在线播放或下载。
- 用户账号、云同步和跨设备同步。
- 内置音频剪辑、转码或标签编辑。
- 联网歌词搜索和版权内容分发。
- 复杂音效处理、专业均衡器和 ReplayGain。
- 直接删除、移动或修改用户原始音频文件。

## 4. 用户与使用场景

### 4.1 目标用户

- 将音乐文件保存在手机本地的普通用户。
- 需要离线播放和低隐私风险的用户。
- 对播放队列、收藏和播放列表有管理需求的用户。

### 4.2 典型场景

| 场景 | 用户目标 |
| --- | --- |
| 首次使用 | 授权后快速看到本地歌曲并开始播放 |
| 日常播放 | 从最近播放或歌曲列表继续听歌 |
| 专辑欣赏 | 打开专辑后按专辑顺序播放 |
| 临时播放 | 搜索歌曲并加入当前播放队列 |
| 长时间播放 | 锁屏后继续播放，并通过通知栏切歌 |
| 音乐整理 | 收藏歌曲，创建并维护个人播放列表 |
| 文件变化 | 音乐文件新增、删除或移动后重新扫描 |

## 6. 页面与导航

建议使用底部导航承载主要入口：

- 首页：最近播放、最近添加、收藏和快捷入口。
- 音乐库：歌曲、专辑、艺术家、播放列表。
- 搜索：统一搜索歌曲、专辑和艺术家。
- 设置：权限、扫描、播放和外观设置。

全局底部迷你播放器在存在当前歌曲时显示，点击进入完整播放页。完整播放页应能够从任意主要页面打开。

## 7. 非功能需求

### 7.1 性能

- 首次打开音乐库后，常规设备应在可接受时间内显示已有索引。
- 扫描、数据库读写和封面加载不得阻塞主线程。
- 具有数千首歌曲时，列表滚动应保持流畅。
- 封面图片应具备内存和磁盘缓存策略。

### 7.2 可靠性

- 播放服务异常退出后，应用应能恢复到可播放状态。
- 单个损坏文件不应导致整个队列停止。
- 数据库升级必须提供迁移策略。
- 扫描过程被中断后，下次扫描可以重新执行而不产生重复数据。

### 7.3 隐私与安全

- MVP 不上传歌曲、播放历史或设备文件信息。
- 仅请求实现功能所需的媒体权限。
- 不主动修改或删除用户原始文件。
- 本地播放历史和播放列表仅保存在应用私有空间。

### 7.4 可用性与适配

- 支持手机竖屏，兼容小屏和大屏设备。
- 关键操作应提供无障碍语义和足够的触控区域。
- 所有加载、空数据、无权限、失败和无结果场景都有明确反馈。
- 支持系统深色模式。

## 8. 数据与行为规则

- 歌曲唯一性优先使用 MediaStore 媒体 ID；记录需要关联当前 URI 和修改时间。
- 无标题时显示文件名，无艺术家时显示“未知艺术家”，无专辑时显示“未知专辑”。
- “播放全部”创建当前上下文的临时播放队列，不自动修改持久化播放列表。
- 从单首歌曲播放时，默认队列至少包含该歌曲；上一首和下一首遵循当前队列规则。
- 应用内移除歌曲只移除索引，不删除设备文件。
- 播放完成后按循环模式决定停止、播放下一首或重新播放。

## 9. MVP 验收标准

- 授权流程在 Android 版本对应权限下可正常完成。
- 授权后可显示设备中的有效本地音乐，并能手动重新扫描。
- 点击歌曲后可以播放、暂停、切换和拖动进度。
- 应用退到后台或锁屏后可以继续播放，通知栏可以控制播放器。
- 耳机拔出后暂停，音频焦点被其他应用占用时行为符合系统规范。
- 可以搜索歌曲、专辑和艺术家，并从结果执行播放或入队。
- 可以收藏歌曲并创建、编辑、播放自定义播放列表。
- 应用重启后能够恢复上次播放歌曲和基本播放上下文。
- 删除或损坏的文件不会造成永久死链或队列崩溃。
- 无权限、无音乐、扫描中、扫描失败、无搜索结果等状态均有明确 UI。
- 在目标测试设备上无崩溃、无明显卡顿和明显布局溢出。

## 10. 后续版本建议

按优先级可考虑：

1. 本地 LRC 歌词和歌词滚动。
2. 睡眠定时器和播放速度。
3. 文件夹浏览与扫描范围配置。
4. Android Auto、桌面小组件和外部设备支持。
5. 均衡器、ReplayGain、无缝播放等高级音频能力。
6. 播放列表导入导出。
