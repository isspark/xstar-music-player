# XSTAR 本地音乐播放器需求文档

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | XSTAR |
| 文档版本 | 2.0 |
| 产品阶段 | MVP 增强版 |
| Android 包名 | `life.xstar.music.player` |

## 2. 产品概述

XSTAR 是一款离线 Android 本地音乐播放器。用户主动选择一个或多个音乐文件夹，应用仅扫描获得长期访问授权的目录，建立本地音乐索引，并提供沉浸式播放、歌曲分类、搜索、收藏、播放队列和自定义播放列表能力。

产品强调本地隐私、播放稳定性和现代化体验：无需登录、不上传文件、不依赖网络服务、不修改原始音乐文件。

当音乐文件没有内嵌封面时，用户可在音乐库的专辑分类中打开专辑详情，手动使用 iTunes Search API 查询封面。在线封面不会在扫描或启动时自动请求；用户可以在设置中关闭在线封面获取。

## 3. 产品目标

### 3.1 MVP 目标

- 支持添加、移除和持久化多个音乐文件夹授权。
- 扫描指定文件夹及其子目录中的常见音频文件。
- 启动后直接进入全屏播放页。
- 支持播放、暂停、上一首、下一首、进度拖动和播放模式切换。
- 支持顺序播放、随机播放和单曲循环。
- 支持后台播放、锁屏、通知栏、耳机和蓝牙媒体控制。
- 支持歌曲、专辑和艺术家浏览与搜索。
- 支持收藏、临时播放队列和自定义播放列表。
- 支持主题色和音乐节拍动态效果设置。
- 应用重启后恢复播放队列、当前歌曲和播放位置。
- 支持本地同名 LRC、LRCLIB 在线歌词和播放页歌词滚动。

### 3.2 非目标

- 在线音乐搜索、在线播放或下载。
- 用户账号、云同步和跨设备同步。
- 联网歌词、版权内容分发和社交功能。
- 音频剪辑、转码和原文件标签编辑。
- 直接删除、移动或修改用户原始音频文件。
- 专业均衡器、ReplayGain 和高级 DSP。

## 4. 用户场景

| 场景 | 用户目标 |
| --- | --- |
| 首次使用 | 选择一个或多个音乐目录并建立音乐库 |
| 日常播放 | 启动后立即查看并控制最近播放内容 |
| 音乐浏览 | 按歌曲、专辑或艺术家查看本地音乐 |

| 音乐整理 | 收藏歌曲并维护自定义播放列表 |
| 外观定制 | 从侧滑菜单选择主题色，在设置中开关节拍效果 |

## 6. 页面与导航

应用默认页面为“正在播放”，不使用底部导航和顶部标题栏。

侧滑菜单页面：

- 正在播放：沉浸式全屏播放器。
- 音乐库：搜索、歌曲、专辑、艺术家和目录选择入口。
- 我的收藏：收藏歌曲列表。
- 播放列表：自定义播放列表管理。
- 设置：节拍动效、音乐文件夹、重新扫描和版本信息。

从音乐库、收藏、专辑、艺术家、队列或播放列表点击歌曲后，应用自动返回播放页。

## 7. 数据与行为规则

- 应用只处理用户通过 SAF 授权的文件夹，不读取无授权目录。
- 文件夹 URI、主题色和节拍效果开关保存于 DataStore。
- 歌曲主键由源文件 URI 的 SHA-256 摘要前 8 字节生成。
- `sourceFolderUri` 标识歌曲所属授权目录。
- 音频内嵌封面保存于应用缓存目录，数据库保存 FileProvider URI。
- 在线封面仅在用户主动点击后使用艺术家和专辑信息查询，不上传音频文件；匹配结果缓存于应用缓存目录。
- 缓存封面丢失时允许重新扫描恢复，不影响音频播放。
- Queue 是临时播放上下文，Playlist 是显式持久化数据，两者互不隐式覆盖。
- 顺序模式在队列末尾停止；随机模式随机并循环队列；单曲模式重复当前歌曲。
- 关闭节拍效果后立即停止动态背景和封面缩放。

## 8. 非功能需求

### 8.1 性能

- 文件扫描、元数据读取、封面提取和数据库写入不得阻塞主线程。
- 动态背景使用 Compose 动画状态，不以音频采样频率刷新 UI。
- 播放进度按轻量固定间隔更新。
- 封面使用磁盘缓存与 Coil 加载。

### 8.2 可靠性

- 数据库升级必须提供迁移，本版本包含 1→2 和 2→3 迁移。
- 单个文件读取失败不终止整个目录扫描。
- 文件或目录授权失效时允许用户重新选择和重新扫描。
- 播放器服务和控制器销毁时正确释放资源和监听器。

### 8.3 隐私

- 不上传歌曲、目录、封面、播放历史和播放列表。
- 使用在线封面补充时会向 iTunes 发送艺术家和专辑名称。
- 设置中的“允许获取在线专辑封面”关闭时，不显示获取按钮且不发起在线请求。
- 目录权限仅申请只读长期访问。
- 不删除或修改用户原始文件。

### 8.4 可用性

- 关键播放控制提供至少 48dp 的触控区域。
- 圆形封面在不同屏幕宽度下保持 1:1。
- 页面兼容状态栏和导航栏安全区域。
- 所有图标提供内容描述。

## 9. MVP 验收标准

- 可以连续添加至少两个不同音乐文件夹，并在重启后保留。
- 只显示已选文件夹及其子目录中的有效音乐。
- 移除目录并扫描后清理对应歌曲索引。
- 启动后进入无标题栏的全屏播放页。
- 播放页封面是正圆形，并优先显示文件内嵌封面。
- 点击音乐库歌曲后开始播放并自动返回播放页。
- 五个播放控制按钮水平对齐，模式切换行为正确。
- 播放队列支持切换、移除和清空。
- 侧滑菜单可以打开并切换页面及主题色。
- 节拍效果可以开关，关闭后背景和封面停止变化，重启后状态不丢失。
- 通知栏、锁屏、耳机和蓝牙控制符合系统媒体行为。
- 应用重启后恢复有效播放队列、当前歌曲和位置。
- 歌词来源优先级为已缓存在线歌词、同名 LRC；没有本地歌词时用户可主动在线获取。
- 安装后 Launcher 显示单个小音乐符号图标。
- 无明显崩溃、卡顿、布局溢出或主线程长时间阻塞。

## 10. 后续版本建议

1. 本地 LRC 歌词和歌词滚动。
2. 睡眠定时器和播放速度。
3. 播放列表拖拽排序和导入导出。
4. 基于真实音频能量或频谱的节拍驱动动效。
5. Android Auto、桌面小组件和 Cast。
6. 均衡器、ReplayGain 和无缝播放。
