产品定位

把音乐还给本地

沉浸式播放页

旋转 CD,氛围随心

  • 启动即入,无标题栏,无底导航
  • 圆形封面播放时缓慢旋转,暂停保留角度
  • 动态主题氛围色与封面脉冲缩放
  • 歌曲名右侧显示音质徽标
  • 点击 CD 切换到歌词页面
  • 顺序 / 随机 / 单曲循环一键切换
FM 黑胶电台

整库随机,黑胶作画

  • 开启即保存现场,从全库随机独立队列
  • 极简黑胶画布:沟槽、内圈标签、边缘高光
  • 外缘闭合圆环展示进度,暂停显示透明标识
  • 整页单击播放/暂停,左右滑动随机换歌
  • 标题上方歌词随播放进度高亮滚动
  • 应用重启继续 FM,关闭即恢复原现场
DLNA / UPnP 投屏

把客厅变成音乐厅

  • 侧滑入口,FM 模式下禁用
  • 手机做 Control Point,发现同一 Wi-Fi 渲染器
  • 自建本地 HTTP 音频流,Range/206 支持 seek
  • 手机全程掌控队列、模式、进度、歌词与封面
  • 本地静音保留现场,断开自动恢复
  • 锁屏/切后台前台服务保活,持续投屏
  • 播放页右上"正在投到 <设备名>"胶囊
音乐库

你的音乐,你的秩序

  • 歌曲 / 专辑 / 艺术家三大分类
  • 关键词搜索,中英文皆可
  • 连续添加多个授权文件夹
  • 移除目录即清理对应索引
  • 手动重新扫描,保留收藏与播放列表

音质识别

每一首歌,都标得清清楚楚

扫描时双 API 读取音频参数,自动按格式、码率、采样率与位深归类,让你一眼分辨音质。

普通 · MP3 / AAC <256kbps
高清 · 有损 ≥256kbps
无损 · FLAC / ALAC / WAV
Hi-Res · ≥24bit 或 >48kHz
MP3 M4A AAC FLAC OGG OPUS WAV WMA

歌曲详情页展示编码、码率、采样率、位深、声道与文件信息,所见即所听。

歌词体验

逐行高亮,随播放滚动

  • 支持 [mm:ss.xx] 与 [mm:ss:xxx] 时间标签
  • 一行多时间标签、UTF-8 BOM 兼容

  • 网易云、QQ、酷狗、酷我、咪咕多平台切换
  • 展示标题、歌手、专辑与来源平台
  • 首次下载引导选择 SAF 下载目录

不上传

不修改
